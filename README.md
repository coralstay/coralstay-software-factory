# coralstay-software-factory

`backlog.md` 마크다운 태스크를 단일 진실 원천으로 삼고, 순수 자바 미들웨어가
Claude Code 프로세스를 Git Worktree 단위로 격리 배정하는 **Git-Native AI 자율 개발
파이프라인** 설계 저장소.

## 문서

| 파일 | 내용 |
| --- | --- |
| [아키텍처.md](./아키텍처.md) | 계층 구조, 자율 워크플로우, 트레이드오프, 수직확장 인프라 최적화까지 집약한 설계 문서 |
| [에이전트_레일_파이프라인.html](./에이전트_레일_파이프라인.html) | 파이프라인 시각화 아티팩트 (브라우저로 열람) |

## 핵심 원칙

- **진실의 원천은 Git.** 에이전트의 모든 발자취를 커밋으로 남기고, 인간용 이력은
  최종 완료 시점의 Squash and Merge로 정리한다.
- **1태스크 1에이전트 1파일 1주제.** Git Worktree로 물리 폴더를 분리해 병렬 작업의
  충돌 확률을 구조적으로 제거한다.
- **규칙은 대상 프로젝트의 테스트가 강제한다.** 미들웨어 할당자는 Exit Code만 심사하고,
  실패 시 에러 로그를 묶어 에이전트에게 자가 치유를 명령한다.
- **상태는 내장 DB, 형상은 Git.** 고빈도 상태/캐시는 인메모리 DB가 받아내고 Git은
  최종 영속화에만 집중한다.
