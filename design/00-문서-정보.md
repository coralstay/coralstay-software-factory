# 0. 블루프린트 정보

이 문서는 Sigkill Foundry의 블루프린트다. 스펙 주도 개발(SDD)을 따른다 — 구현은 이 명세에서
도출하고, 명세와 코드가 어긋나면 명세를 먼저 고친 뒤 코드를 맞춘다.

## 규범 용어

| 표현 | 뜻 |
| --- | --- |
| 반드시 ~한다 (MUST) | 어기면 명세 위반이다 |
| ~해야 한다 (SHOULD) | 어길 때는 이유를 11장 설계 결정에 남긴다 |
| ~할 수 있다 (MAY) | 선택 사항이다 |

## 요구사항 표기

- 요구사항은 `<영역>-<세 자리 번호>`로 식별한다. 번호는 재사용하지 않는다.
- 영역: `ORC`(오케스트레이터) · `RAIL`(claude-rails) · `TRL`(커밋 트레일러) · `BL`(backlog.md 규약) · `NFR`(비기능).
- 모든 요구사항은 수용 기준을 하나 이상 가진다(10장).
- 아직 정하지 않은 값은 `TBD(Q-n)`으로 적고, `Q-n`을 12장 미결 사항에 둔다.

## 추적 규칙

- 요구사항 하나는 backlog 태스크의 AC로 내려간다. 태스크 카드는 자신이 구현하는 요구사항 ID를 적는다.
- 원칙(2장)에 어긋나는 요구사항은 둘 수 없다. 원칙을 바꾸려면 11장에 결정을 먼저 남긴다.
