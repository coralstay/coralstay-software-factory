# 참고 노트

[부록 · 참고 문헌](../부록-참고-문헌.md)에 번호를 받은 문헌 중, 설계 판단에 쓸 만큼 깊이 읽은 것의 **읽기 노트**를 둔다.
목록(번호 · 서지 · 한 줄 관계)은 부록이 SSOT이고, 이 디렉터리는 그 번호 하나에 노트 하나를 붙인다.

## 파일 이름

`<부록 번호>-<arXiv ID 또는 짧은 이름>.md` — 예: `54-2512.08296.md`. 번호는 부록과 같게 두고 재사용하지 않는다.

## 노트 형식

1. **서지** — 제목 · 저자 · 소속 · 식별자(arXiv ID · DOI) · 읽은 버전과 날짜 · 라이선스 · 링크 · 동료심사 여부
2. **요약** — 자기 말로 쓴다. 수치마다 어느 버전 · 어느 절 · 표에서 왔는지 적는다
3. **재는 것과 닿는 범위** — 종속변수(무엇을 쟀나)와 실험 범위. 부록의 인용 원칙 3 · 4를 여기서 판단한다
4. **이 설계와의 연결** — 목표(G-n) · 리스크(R-n) · 장 번호 · 컴포넌트 카드처럼 실제로 가리킬 수 있는 곳에만 연결한다. 근거로 쓰지 않는 곳도 적는다
5. **열린 질문** — 이 설계에서 아직 정하지 않은 것 중 이 문헌이 판단을 도울 수 있는 것

## 저작권

- 원문 PDF · 원문 HTML 사본을 저장소에 넣지 않는다. 링크만 둔다.
- 인용은 한 문장 이내만, 따옴표와 출처 절을 붙여 쓴다. 나머지는 자기 말로 요약한다.
- 재배포를 허용하는 라이선스(CC BY 등)라도 이 원칙을 기본으로 한다.
