# 2.03 기능 요구사항

> 작성 전

시스템이 반드시 해내는 동작을 영역별 요구사항 ID로 적는다 (ORC- · RAIL- · TRL- · BL-).

## 담을 내용

- [ ] ORC — agent-orchestrator: 스케줄 · 스폰 · 회수
- [ ] RAIL — interlock: 태스크 읽기 · 상태 전이 · 테스트 게이트
- [ ] TRL — coding-agent-git-commit-tool: 커밋 트레일러 · 토큰 계량
- [ ] BL — backlog.md 사용 규약: 계층 · 상태 · AC
- [ ] 요구사항마다 상위 목표(G-n)와 수용 기준(4.02) 연결
